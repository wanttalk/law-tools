# 訴訟工具箱

自用的離線網頁小工具，全部在瀏覽器裡跑，**沒有任何連線、不蒐集資料**。
貼進去的文字只留在你自己的裝置上。

線上版：<https://wanttalk.github.io/law-tools/>

| 工具 | 做什麼 |
|---|---|
| [書狀排版器](書狀排版器.html) | 貼上純文字，自動判讀狀名、案號股別、當事人欄、壹一（一）1. 各層編號、證據清單、謹狀，套成標楷體 16pt／1.5 行距／A4 版面。所有排版參數可即時調整，可列印存 PDF、複製含排版貼進 Google 文件、下載 Word 或 Markdown |
| [引文比對器](引文比對器.html) | 貼原文＋貼引文，逐字比對是否為原文的連續子字串；對不上時標出多字／少字／改字 |
| [證據編號檢查器](證據編號檢查器.html) | 貼狀子全文，檢查證物編號跳號、重複、漏引、引到清單沒有的證物、中文與阿拉伯數字混用 |
| [期限計算器](期限計算器.html) | 送達日＋期間 → 到期日。依民法 120Ⅱ 始日不算入起算、122 條末日遇休息日順延，可加計在途期間 |
| [利息抵充計算器](利息抵充計算器.html) | 依民法 323 條「先充費用、次充利息、次充原本」逐筆抵充，輸出可貼進書狀的算式 |
| [金額大寫轉換](金額大寫轉換.html) | 數字轉國字大寫，看得懂「68萬2,683」這類混寫 |

## 使用注意

這些工具只做機械性的排版與試算，**不取代法律判斷**：

- 期限計算器**不內建國定假日**（每年公告不同、還有補班日），需自行貼入該年度休息日；
  實際期限一律以法院通知與司法院在途期間標準表為準。
- 利息抵充計算器採單利、按日計息的簡化模型；複利、違約金、分段利率不處理。
- 引文比對是機器關，通過後仍應點開司法院裁判書查詢網址人工二次確認。
- 排版器不修改任何文字內容（不換標點、不補字、不刪字），只判斷段落型別並套用格式。

## 結構

單檔工具，沒有建置流程、沒有相依套件。`assets/tool-ui.css` 是共用外觀，
新增工具只要放一個 HTML 進來、`<link>` 這支 CSS，再到 `index.html` 加一張卡片。

本 repo **只有工具程式碼**，不含任何案件資料。
